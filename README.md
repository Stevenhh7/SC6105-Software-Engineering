# SC6105 Software Engineering

SC6105 软件工程课程团队项目。由 4–6 人组成团队，围绕实际问题完成需求分析、设计、开发、测试和软件原型展示。

## 项目文档

- [课程项目要求](课程项目要求.md)：完整交付清单、时间节点、提案要求和建议执行顺序。
- [文件存放约定](AGENTS.md)：后续文件的默认保存位置。

## 提交时间表

| 截止时间 | 阶段 | 主要交付物 |
| --- | --- | --- |
| 第 2 周末 | 项目提案 | 团队信息、提案文档、成员简历 |
| 第 5 周末 | 需求分析 | SRS、需求模型、UI 界面草图 |
| 第 9 周末 | 设计、实现与测试 | 设计与测试文档、完整设计模型、系统架构、应用程序骨架、测试框架 |
| 第 10 周末 | 展示材料 | PPT 文件、MP4 演示视频 |
| 第 11、12 周 | 项目展示 | 项目汇报、软件原型演示 |

具体日历日期以课程安排为准。每次提交都必须包含各成员的个人贡献说明。

## 开始前要完成的事项

- [ ] 组成 4–6 人团队，选出组长。
- [ ] 确定团队名称、项目名称和成员分工；团队成立后不得更换成员。
- [ ] 明确目标用户、要解决的问题和项目范围。
- [ ] 确定初步技术方案，安排进度并绘制甘特图。
- [ ] 收集成员简历，编写项目提案。
